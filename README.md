# hayaalalfalah.com

MosqueConnect community platform with a Next.js frontend and multiple Node.js backend services.

## Deployment setup

This repository is configured for:

- **Vercel** hosting for the `frontend` Next.js app.
- **GitHub Actions** automation for CI, Docker image publishing, and Vercel deployments.
- **Docker Compose** backend runtime for service containers plus Postgres and Redis.

See `docs/deployment.md` for the production setup steps.
